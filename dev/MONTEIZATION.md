# Monetization Strategy

Rayshio can be valuable, but maybe not so valuable that it can only be paid for.

Instead, let's create options for the user:

## Hosted Online (paid)

### Free

- One month free trial. After, locked into read-only.
- One mailbox
- Aggregate all invoices into a dashboard

### Basic

- Invoices are categorized, enable multi-department

### Autonomous

- Invoices are automatically emailed to your accountant's email / service

## Self-Hosted

### Own Hardware

Comes out-of-the-box with Docker instances of PostgreSQL and MongoDB.

### Railway Hosted

Ready to be deployed on Railway
